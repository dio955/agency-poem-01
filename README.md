# agency-poem-01

A poem about agency: the power to choose and to act, and the handover of
that power — from a grandmother's hands teaching knitting, to an agent taught
the same way, to the moment of taking the choosing back.

`main.ts` writes the poem to `/output/entry.txt` (Node 22, standard library
only, deterministic). The poem is 14 lines, well inside the 1–1,000 character
limit.
